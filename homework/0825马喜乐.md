**STM32（弱电）不能直接驱动舵机/电机（强电）**，否则电流不足、电压不匹配、反电动势冲击，会导致芯片烧毁或反复重启。

**必须遵守：信号走MCU，功率走外部电源，两者GND必须共地。**

------

## 为什么不能直连？

| 问题           | 说明                                                         |
| :------------- | :----------------------------------------------------------- |
| **电流不够**   | STM32的GPIO最多输出20mA，舵机/电机启动瞬间需要几百mA到几A，直接烧IO口。 |
| **电压不匹配** | STM32是3.3V逻辑，舵机需要5V~6V，电机需要5V~24V，3.3V根本带不动。 |
| **反电动势**   | 电机是感性负载，启停瞬间产生几十伏反向尖峰，会击穿MCU。      |

------

## 解决方案

### 1. 独立外部供电

舵机/电机**必须用自己的电池或电源适配器**，**严禁**从开发板的3.3V/5V取电。

### 2. 必须共地

外部电源的**负极**和STM32开发板的**GND**必须用导线连起来，否则信号无法识别，舵机会乱抖。

### 3. 区分两种器件的接法

| 器件         | 接法                                                         |
| :----------- | :----------------------------------------------------------- |
| **舵机**     | 红色（VCC）→ 外部电源；棕色（GND）→ 共地；信号线 → 直连STM32 GPIO（安全） |
| **直流电机** | **不能直连STM32**，必须通过驱动模块（如TB6612、L298N），由驱动模块去放大电流控制电机。 |

> **补充保护**：电机两端并联一个续流二极管（如1N5819）和一个小电容（0.1μF），用来吸收反电动势和火花干扰。

# 一、伪代码

### 1. timer.c ：
```c
#include "timer.h"
#include "stm32f4xx.h"

void TIM14_Init_1ms(void)
{
    TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;

    // 1. 开启 TIM14 时钟 (TIM14 位于 APB1 总线)
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM14, ENABLE);

    // 2. 配置时基结构体 (84MHz / 84000 = 1kHz，即 1ms/次)
    TIM_TimeBaseStructure.TIM_Prescaler = 83999; 
    TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up; // 向上计数
    TIM_TimeBaseStructure.TIM_Period = 65535;// ARR 设为最大，防溢出
    TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;

    TIM_TimeBaseInit(TIM14, &TIM_TimeBaseStructure);

    // 3. 使能 TIM14 计数器
    TIM_Cmd(TIM14, ENABLE);
}
void delay_ms(uint8_t count)
{
    // 1、先将 tim 的计数器清空 (0)
    TIM_SetCounter(TIM14, 0);

    // 2、去获取计数器的值与 count 进行比较，等计数值达到 count
    while (TIM_GetCounter(TIM14) < count);
}
```

# 二、电机与驱动模块信息（MG310 霍尔电机 + TB6612 双路稳压版）

### 1. MG310 直流减速电机规格（霍尔编码器版，轴径 3mm）
* **额定供电电压**：**7.4V**（推荐使用 2S 动力锂电池组供电，满电 8.4V）。
* **机械规格**：**输出轴径 3mm（D 型削边切位轴）**，减速比 **1:20**。
* **电流与功率**：额定工作电流 **<= 0.5A**，堵转电流 **<= 2.0A**，额定功率 **<= 3W**。
* **转速与力矩**：额定负载转速 **400 +- 52 rpm**（空载 500 +- 65 rpm），额定扭矩 **0.4 kg.cm**（堵转扭矩 1.5 kg.cm）。
* **电机本体参数**：电枢电阻 4.5 欧姆，电感 30.7 mH，反电动势常数 0.00064 V/rpm。
* **霍尔编码器参数**：
  * 编码器精度：**13 ppr**（电机转子轴每转一圈单相输出 13 个脉冲）。
  * 供电电压：**3.3V ~ 5V**（推荐 5V，严禁超过 5V）。
  * 单圈总计数：配合 1:20 减速比与 STM32 定时器四倍频接口：`单圈脉冲 = 20 * 13 * 4 = 1040 个脉冲计数`。

### 2. TB6612 双路驱动模块带稳压版（D153C / D153B）
* **动力输入电压 (VM)**：**4.5V ~ 15V**（接外部 7.4V 锂电池）。
* **驱动电流能力**：单路持续 **1.2A**，峰值 **3.2A**（轻松带动 MG310 的 0.5A 额定电流与 2.0A 堵转电流）。
* **板载稳压输出**：
  * 开关降压输出 **5V / 5A**（RT8289 芯片）与 LDO 输出 **3.3V**（RT9013 芯片），可直接为单片机和传感器供电。
* **动力电压分压检测 (ADC)**：
  * 板载 1/11 分压电路引出至 ADC 引脚，计算公式：`输入电压 = ADC采集值 * (3.3 * 11 / 4096)`。
* **使能与 PWM 控制**：
  * `STBY` 引脚：必须接 **3.3V 或 5V 高电平**才能使能驱动工作。
  * 推荐 PWM 频率：**10 kHz**（调速平稳无噪音）。

### 3. 6-Pin 电机端子线序与驱动板端子对应

| 排线序号 | 电机丝印标注 | 导线颜色 | 功能说明 | 对应 TB6612 驱动板端子 |
| :---: | :--- | :---: | :--- | :--- |
| **Pin 1** | **电机线+** | 黄色 | 电机动力正极 | `AO2` (或 `BO1`) |
| **Pin 2** | **编码器GND** | 棕色/红色 | 编码器参考地 (0V) | 驱动板 `GND` |
| **Pin 3** | **编码器B相** | 绿色 | 正交方波脉冲 B 相 | 驱动板 `E1B` / `E2B` |
| **Pin 4** | **编码器A相** | 白色 | 正交方波脉冲 A 相 | 驱动板 `E1A` / `E2A` |
| **Pin 5** | **编码器5V**  | 黑色/棕色 | 编码器供电正极 (3.3V~5V) | 驱动板 `5V` (稳压输出) |
| **Pin 6** | **电机线-** | 棕色/黑色 | 电机动力负极 | `AO1` (或 `BO2`) |

### 4. 关键接线方案（以 STM32F407ZGT6 开发板为例）
* **系统供电与共地**：
  * 驱动板 5V 输出 -> 开发板 **+5V** (P9 端子 Pin 57/58)
  * 驱动板 GND -> 开发板 **GND** (P9 端子 Pin 55/56)（**必须严格共地**）
* **使能端 (STBY)**：接开发板 **+3.3V**（常开）或 **PD3**（GPIO 软件控制）
* **电机 A 控制**：
  * `PWMA` -> **PA0** (TIM5_CH1 / TIM2_CH1，10kHz PWM 调速)
  * `AIN1` -> **PE0** (推挽输出)
  * `AIN2` -> **PE1** (推挽输出)
  * 编码器 `E1A` -> **PB6** (TIM4_CH1)
  * 编码器 `E1B` -> **PB7** (TIM4_CH2)
* **电机 B 控制**：
  * `PWMB` -> **PA1** (TIM5_CH2 / TIM2_CH2，10kHz PWM 调速)
  * `BIN1` -> **PE2** (推挽输出)
  * `BIN2` -> **PE3** (推挽输出)
  * 编码器 `E2A` -> **PC6** (TIM3_CH1)
  * 编码器 `E2B` -> **PC7** (TIM3_CH2)
* **电池电压采样**：
  * 驱动板 `ADC` -> **PA6** (ADC1_IN6)

### 5. 核心安全注意事项
1. **严禁 GPIO 直连电机**：单片机引脚输出能力仅 20mA，带动电机必烧 MCU。
2. **独立动力供电与严格共地**：动力电源（7.4V 锂电）只给驱动板 VM 供电；电池负极、驱动板 GND 与单片机 GND 必须连通共地。
3. **严禁带电插拔电机线**：电机线圈断开瞬间反电动势高达几十伏，会击穿 TB6612 驱动芯片。
4. **编码器供电限 5V**：严禁给编码器接入超过 5V 的电压，防止烧毁霍尔传感器或反向倒灌损坏单片机。
5. **PID 极性防飞车**：若开启速度闭环后电机满速暴冲，在中断中将编码器读数取反：`encoder = -Read_Encoder(...)`。

## 📜 关键工程配置与换算

```c
/* 1. TIM3 PWM 时钟配置 (84MHz)
 * PSC = 0, ARR = 8399 => 频率 = 84MHz / (8399 + 1) = 10kHz
 * 比较值 = speed_percent * 84 (0 ~ 100%)
 *
 * 2. TIM4 编码器 4 倍频测速与 RPM 换算 (MG310: 减速比 1:20, 13 PPR)
 * 每转一圈脉冲数 = 13 * 4 * 20 = 1040 PPR
 * TIM6 每 100ms 触发一次测速中断:
 * RPM = (Delta_Pulse / 1040) / 0.1 * 60 = Delta_Pulse * 600 / 1040
 *
 * 3. ADC 母线电压换算 (10k:1k 分压网络, 1/11 分压比)
 * V_Bus = ADC_Val * (3.3V / 4095) * 11 = ADC_Val * 36.3V / 4095
 */
```

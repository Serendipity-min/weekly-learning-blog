## ⚙️ 硬件连接速查（STM32F407ZGT6）

| TB6612 驱动板端子 | STM32F407 引脚 | 排针位置 | 复用外设功能 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **PWMA** | **PB1** | P8 Pin 35 | **TIM3_CH4** | 10kHz PWM 调速输出 |
| **PWMB** | **PB0** | P8 Pin 36 | **TIM3_CH3** | 10kHz PWM 调速输出 |
| **AIN1 / BIN1** | **PE0** | P9 Pin 53 | GPIO 推挽输出 | 方向控制 1（避开板载 SPI Flash 片选 PB14） |
| **AIN2 / BIN2** | **PE1** | P9 Pin 52 | GPIO 推挽输出 | 方向控制 2（避开板载 LCD 背光使能 PB15） |
| **STBY** | **+3.3V** | P9 Pin 59 | 逻辑高电平 | 驱动芯片常开使能 |
| **GND** | **GND** | P9 Pin 55/56 | 系统公共地 | **动力电源负极、驱动板 GND 与单片机严格共地** |

## 📜 关键工程配置

```c
/* TIM3 时钟基准: APB1 定时器倍频后为 84MHz
 * 配置 PSC = 0, ARR = 8399
 * PWM 频率 = 84MHz / (0 + 1) / (8399 + 1) = 10,000 Hz (10 kHz)
 * 比较值换算: compare_val = speed_percent * 84 (0 ~ 100%)
 */
```

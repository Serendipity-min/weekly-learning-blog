# STM32 Console MCP 交付前审查

## 工具权限

| 工具类别 | 操作 | 防护 |
| --- | --- | --- |
| 只读 | `ping`、`info`、`status`、`led_get` | 固定命令白名单、串口互斥锁、512 字节响应上限 |
| 可逆写入 | `led_set` | 参数仅允许 `on` / `off`，并标记为 destructive hint |
| 不可逆操作 | `flash_project_firmware` | 固定固件、固定端口、显式确认值、芯片 UID 校验、写入后验证 |

## 结论

未发现任意命令执行、任意文件读写、未授权网络暴露、密钥泄露或未经限制的串口透传入口。服务适合在本机受控开发环境使用。

## 运行约束

- 烧录前必须在当前对话中获得用户明确授权；仅有确认参数不足以证明用户身份。
- 不要以管理员身份运行 MCP 服务。
- 新增蓝牙、网络或固件上传功能前，需重新进行威胁建模与安全扫描。

# STM32F407 EXTI 外部中断实验操作与观察指南（KEY0 版）

本文档指导如何在 Keil MDK 环境中基于 **KEY0 按键（PE4，按下接地）** 编译、下载并观察 **任务 1（边沿触发模式与按键抖动）** 和 **任务 2（中断挂起标志位清除与中断风暴）** 的实验现象。

---

## 一、硬件特性与电平变化（KEY0 vs 原 PA0）

这是非常重要的硬件电气特性区别：

| 参数 | 原 PA0 (WK_UP) | **当前 KEY0** |
| :--- | :--- | :--- |
| **引脚连接** | MCU `PA0`，按下接 `+3.3V` | MCU **`PE4`**，按下接 **`GND`** |
| **GPIO 模式** | 下拉输入 (`GPIO_PuPd_DOWN`) | **内部上拉输入 (`GPIO_PuPd_UP`)** |
| **中断线 / 向量** | `EXTI_Line0` / `EXTI0_IRQHandler` | **`EXTI_Line4` / `EXTI4_IRQHandler`** |
| **未按下电平** | 低电平 `0V` | **高电平 `3.3V` (`1`)** |
| **按下瞬间电平跳变** | `0 -> 1` (**上升沿**) | **`1 -> 0` (【下降沿】)** |
| **松开手指电平跳变** | `1 -> 0` (**下降沿**) | **`0 -> 1` (【上升沿】)** |

> **核心结论**：
> 因为 KEY0 按下接地（低电平有效）：
> - **`EXTI_Trigger_Falling`（下降沿触发）** 对应 **【按下 KEY0 瞬间】** 触发！
> - **`EXTI_Trigger_Rising`（上升沿触发）** 对应 **【松开 KEY0 瞬间】** 触发！

## 二、实验切换操作（改一个数字一秒切换）

在 Keil 左侧工程树的 **USER** 组中双击打开 [task_config.h](file:///E:/stm32/STM32F407_Template/USER/task_config.h)，修改第 31 行：

```c
#define CURRENT_TASK    1   // 改为 1 ~ 5
```

修改后按 **F7**（编译，0 Error 0 Warning），按 **F8**（下载到开发板）。

## 三、5 个数字对应的实验现象速查

| 数字 | 对应实验文件 | 触发边沿配置 | 按键动作与预期现象 |
| :---: | :--- | :--- | :--- |
| **`1`** | `task1_exti_rising.c` | 上升沿 (`Rising`) | **按下 KEY0 时无反应**；**【松手瞬间】** 产生上升沿，LED0 状态翻转，`g_exti_count` + 1。 |
| **`2`** | `task1_exti_falling.c` | 下降沿 (`Falling`) | **【按下 KEY0 瞬间】** 产生下降沿，LED0 状态翻转，`g_exti_count` + 1；**松开手指无反应**。 |
| **`3`** | `task1_exti_both_edges.c` | 双边沿 (`Rising_Falling`) | 理想情况下按一下触发 2 次（按下亮、松开灭）；**实际由于机械弹片抖动，单次按压可触发多次中断，LED 状态随机**。 |
| **`4`** | `task2_exti_clear_flag.c` | 正常清除标志位 (`CLEAR=1`) | 中断正常调用 `EXTI_ClearITPendingBit(EXTI_Line4)` 清除 PR4；`g_exti_count` 单次累加，`g_main_count` **持续全速递增（主程序畅行无阻）**。 |
| **`5`** | `task2_exti_storm_no_clear.c` | 故意不清除标志位 (`CLEAR=0`) | **【中断风暴】**：首次按下按键后手彻底松开，`g_exti_count` **疯狂狂飙（数十万次/秒）**，`g_main_count` **几乎完全停滞**，LED0 微秒级高速翻转呈**微弱常亮**！ |

## 四、Keil Watch 窗口观察配置

1. 按 `Ctrl + F5` 进入仿真调试。
2. 勾选 **View -> Periodic Window Update**（开启实时刷新）。
3. 打开 **View -> Watch Windows -> Watch 1**，添加：
   - `g_exti_count`（中断执行次数）
   - `g_main_count`（主循环执行次数）
4. 按 `F5` 全速运行，观察按键按下前后计数器的变化。

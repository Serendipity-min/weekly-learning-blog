## 二、电学基础要点回顾

### 2.1 基本概念

- **电路三要素**：电源（提供电能）、负载（消耗电能）、中间环节（传递与控制电能）。
- **三种状态**：通路（正常工作）、断路（电流被切断）、短路（电源正负极直连，⚠️危险）。
- **电流 I**：电荷的定向移动；方向与电子运动方向相反；单位安培 A。换算 `1A = 1000mA = 10⁶μA = 10⁹nA`。
- **电压 U**：电势差，单位伏特 V；`1V×1A×1s = 1J`。STM32 GPIO 输出 **3.3V**，开发板直流输入 DC 6~24V。
- **电阻 R**：导体对电流的阻碍作用，单位欧姆 Ω。
- **强弱电**：弱电（AC<36V / DC<24V，用于信号）vs 强电（220V+，用于能量）——**强电严禁手摸**。

### 2.2 电路定律

- **欧姆定律**：`I = U / R` —— 电路分析的第一性原理。
- **功率**：`P = U × I`。
- **串并联**：串联分压（电流相同），并联分流（电压相同）。
- **基尔霍夫电流定律（KCL）**：流入结点的电流之和 = 流出结点的电流之和（电荷守恒）。
- **仿真工具**：CircuitJS（轻量、绿色免安装，适合验证电路原理）。

### 2.3 常用元器件（重点）

| 元器件 | 核心参数 | 典型应用 | 记忆点 |
|---|---|---|---|
| 电阻 | 阻值/功率/精度 | 限流、分压、上拉下拉 | 色环/数字标注识别法 |
| 电容 | 容量/耐压 | 滤波、耦合、储能 | 阻直通交，容抗 Xc |
| 电感 | 电感量 | 储能、滤波（DC-DC） | 通直隔交，阻高频通低频 |
| 保险丝/熔断器 | 熔断速度/额定电压电流 | 过载、短路保护 | 慢速/快速熔断 |

- **上拉/下拉电阻**：把不确定信号钳位到高/低电平；典型值 GPIO/复位 10kΩ、I2C 标准 4.7kΩ、快速 2.2kΩ。
- **LED 限流电阻计算**：`(5V − 2V) / 10mA ≈ 300Ω`，常用 100/220/330/470Ω。
- **芯片科普**：MCU（控制，STM32/ESP32）vs CPU（通用计算，Intel/AMD）vs GPU（并行计算，NVIDIA）——定位、功耗、实时性差异很大。

## 三、模拟电路要点回顾

- **模拟信号是连续的**，数字信号是离散的；嵌入式开发主要用晶体管/MOS 管做**开关电路**，放大滤波是硬件工程师的事。
- **继电器**：电 → 磁 → 机械触点，实现"用电控制电"，但体积大、速度慢，集成电路里用三极管/MOS 替代。
- **二极管**：单向导电性衍生出整流、续流、电压钳位、防反接、稳压五大应用。
  - 续流二极管：继电器/电机线圈断开时必须反向并联，否则反电动势会打坏器件。
- **稳压二极管**：工作在反向击穿区，配合限流电阻实现稳压（如 15V → 5V）。
- **三极管（NPN/PNP）**：电流控制电流；截止/放大/饱和三状态；`Ic = β × Ib`。
  - 蜂鸣器驱动：IO 电流不足，需要三极管/MOS 管扩流。
- **MOS 管（NMOS/PMOS）**：电压控制电流；栅极几乎不取电流，静态功耗极低，是数字控制与功率开关的绝对主力。
  - 选用口诀：**做开关选 MOS，做模拟放大选三极管**。
- **综合实战**：一键开关机电路（二极管 + 三极管 + MOS 管组合）。

## 四、数字电路要点回顾

- **数制与码制**：二进制补码（最高位符号位，负数补码 = 数值位取反 + 1），C 语言已学过，这里用电路再实现一遍。
- **比较器（运放）**：比较两路输入电压产生输出；光敏电阻 + 电位器阈值实现光照检测。
- **逻辑门**：与、或、非为三大基础门，其他门均可由它们组合而成（配合 Digital 仿真软件看真值表）。
- **运算器演进**：半加器（异或+与）→ 全加器（三输入，两个半加器+或门）→ 四位加法器（串联）。
- **存储单元演进**（本周最有价值的一条主线）：
  - **SR 锁存器**：两个与非门互锁，能"记住"1 位状态，但 S=R=0 无意义；
  - **带 En 的 D 锁存器**：电平触发，En=1 时输出跟随 D；
  - **边沿触发的 D 触发器**：只在时钟上升沿瞬间采样 D，抗干扰更强；
  - **寄存器**：多个 D 触发器并联，同时存储多位数据。
- **工具**：Digital（开源数字电路仿真，需 Java 17）。

## 五、PCB 制作要点回顾（嘉立创 EDA）

### 5.1 PCB 基础

- **PCB 优点**：高密度、高可靠、可设计/生产/测试/组装/维护。
- **单/双/多层板**：双面板=两片单面板背靠背；四层板在顶层底层间插入电源/地内电层。
- **四层板层叠**（Stackup 1 优先）：Top 信号 → GND 内电层（负片）→ VCC 内电层（负片）→ Bot 信号。
- **内电层 vs 信号层**：内电层整片铜箔负片设计、禁走线只分割；信号层正片设计、自由走线。

### 5.2 EDA 软件对比

| 软件 | 费用 | 定位 |
|---|---|---|
| Cadence Allegro/ORCAD | 年授权 ~30 万 | 多层高密度、芯片设计，学习难度高 |
| Mentor PADS | 年授权 ~10 万 | 芯片设计 + 普通集成电路 |
| Altium Designer | 年授权 ~5 万 | 企业主流，收费 |
| **嘉立创 EDA** | **免费** | 国产开源、与立创商城打通、一键打板 ✅ |

### 5.3 设计全流程（已实操）

1. **创建工程**：命名规范 `工程名-版本号-创建日期`；单位 mil（`1mm = 39.37mil`）。
2. **原理图绘制**（LED 开关例程）：`Shift+F` 调出器件库（电池盒 C5290176、300Ω 电阻 C2897009、开关 C2837531、LED C2895470）→ `Alt+W` 连线 → 空格旋转 → DRC 检查通过。
3. **PCB 绘制**（按键开关例程）：`Alt+I` 从原理图导入 → 调整布局（支持翻面）→ 绘制板框（板框层）→ 加圆角。
4. **布线**：蓝色细线是飞线（逻辑连接视图）；信号线 15mil、电源线 30mil；`Tab` 调整线宽；PCB 连线**避免直角**。
5. **网络与铺铜**：同名网络引脚必须连在一起；定义 GND 网络后顶层（`Alt+T`）/底层（`Alt+B`）铺铜。
6. **DRC 检查 → 3D 仿真 → PCB 下单（领优惠券）→ 元器件下单（BOM 标准化检查）**。

### 5.4 元件设计

- 器件 = **元件符号 + 封装**（+实物照片 + 3D 模型，一般不用管）。
- 常用封装：电阻/电容/LED 选 **0603/0805**；STM32 用 LQFP48/64；晶振 3225；排针 2.54mm；MOS 用 SOT23。
- 数据手册尺寸（如 0402 = 1.0×0.5mm）决定真实焊盘大小。

### 5.5 实战项目

| 项目 | 要点 |
|---|---|
| **无接触式电笔** | 三级共射放大（8050/9013，β=64~300），把感应探头微弱信号逐级放大点亮 LED |
| **USB 扩展坞** | HUB 芯片 SL2.1A（C6798314）+ 4×USB-A + Type-C + 晶振；**差分信号** D+/D- 抗干扰；差分布线：平行等长、尽量短、≤2 对过孔、长度差 ≤5mil |
| **STM32F103 最小系统** | 电源（USB 5V → LDO 3.3V / DCDC）、时钟（8MHz HSE + 22pF 负载电容、PLL 倍频 72MHz）、BOOT 启动电路、复位电路、SWD 调试接口、GPIO 引出 |
